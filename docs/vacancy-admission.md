# Vacancy assessment admission

The parcel vacancy tier is `unknown` until both current live generations have independently reviewed source evidence. A bounded county capture or a fixture is **not** a coverage validation. No countywide capture or admission is performed by this change.

The operator must first review the saved `ingest_captures` manifest, every HTTP receipt and source identity, source terms, county coverage, repeat-scan count and snapshot stability, observed structure statuses and their current meanings, and the official effective `AV` appraisal year. Resolve unsafe PIN and geometry linkage before asserting coverage. Record the public source URL and source-as-of date. Do not approve a provisional or future assessment year. The fixture generation table cannot be admitted.

For each of the latest `union_structures_171` and `union_assessed_value_0` captures, insert one `vacancy_live_validation` record binding **exact** `generation_id`, `capture_id`, `source_name`, and `normalized_sha256`. Include `source_url` matching every manifest request (without query string), `terms_evidence`, `coverage_evidence`, `count_evidence`, `snapshot_evidence`, and `source_as_of`. Structure admission additionally requires `status_evidence` and a nonempty `current_statuses` array of statuses established to mean current footprints. Assessment admission requires `effective_av_year`, with no structure statuses. These are operator-reviewed findings, not booleans or inferred gates. Database triggers reject missing/failed HTTP receipts, wrong source URLs, non-current captures, and in-place edits to validated decisions. Corrected replays invalidate their admission and derived assessments.

After both admissions, manually run `landman run union.gis.vacancy_assessments` through the normal Runner. There is no schedule. The run checks both current generations and approved year before publishing parcel-keyed assessments in one transaction. Existing parcel observations have no asserted row version until a fresh accepted parcel publication records one; those parcels remain unknown rather than inheriting the removed boolean. An unadmitted or failed refresh does not publish strong candidates. List, map, and details serve `unknown` if the parcel observation, row version (including a direct geometry or parcel-fact write), live generation, or its admission no longer matches; the operator must review and republish. Single-ring footprints are tested for positive-area overlap in stored CRS. Multi-ring or invalid source geometry leaves the county assessment unknown rather than implying no building. Identical selected-year `AV` duplicates collapse; missing or competing values yield unknown.

This process is a future operator workflow, not proof of live source approval or V1 readiness. Test captures using `example.test` exist only in isolated disposable PostGIS fixtures.
