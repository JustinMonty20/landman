# Parcel evidence

Parcel imports keep every count response and feature page in private local files. The default directory is `~/.local/share/landman/parcel-evidence`. Set `PARCEL_EVIDENCE_DIR` to a private directory to use another location. The directory and snapshot directories must have mode `0700`. Response and manifest files use mode `0600`. Keep the directory backed up. Files are not deleted automatically.

Run `landman run union.gis.parcels` for a full source observation. Run `landman reprocess union.gis.parcels --limit N` for a bounded live repair. Both commands use the county host lock and the ten-minute job limit. The repair fetch has an additional two-minute limit. The database stores snapshot IDs, not local paths.

Run `landman replay union.gis.parcels --snapshot ID` to use a complete saved snapshot without contacting the county. Find published IDs in `parcel_evidence_observations.artifact_id`. An operator may also select the ID of a complete local capture when the database is empty or its first publication failed. Rebuild retains the original capture time and records `offline_rebuild` or `offline_retry`. A known snapshot must match the database manifest and each current PID source hash and version. Older snapshots validate but cannot replace newer evidence. Current replay can publish a normalization correction. It does not report a new county observation. Geometry corrections reconcile stored soil and qualification dependencies. Owner-only corrections do not rerun soil intersections.

Checksums prove local byte integrity. They are not a signed county authenticity claim. A truly empty database must trust the operator-selected complete local evidence. A complete local capture proves that the stored response bytes passed the count and page checks. Offset pages do not prove that the county served all pages from one transactional instant. The original CRS remains in the manifest and source response. Source JSON numbers remain exact in the response files. The parcel table stores a 3857 working geometry. Esri 102100 and EPSG 3857 are accepted as Web Mercator aliases; other or missing declarations stop the import.
