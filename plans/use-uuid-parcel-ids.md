# Use UUID primary keys for parcels

## Context
- User wants `parcels.id` to be a UUID instead of a generated numeric ID.
- The initial migration is still being audited before use, so edit `000001_init_schema.*.sql` directly rather than adding a corrective migration.

## Approach
- Change `parcels.id` from `BIGINT GENERATED BY DEFAULT AS IDENTITY` to `UUID DEFAULT gen_random_uuid()`.
- Enable `pgcrypto` for `gen_random_uuid()`.
- Change `parcel_sales.parcel_id` foreign key from `BIGINT` to `UUID`.
- Keep `parcel_sales.id` as a numeric internal row id unless the user asks all table ids to be UUIDs.

## Files to modify
- `db/migrations/000001_init_schema.up.sql`
- `db/migrations/000001_init_schema.down.sql`
