# Soil screening implementation checkpoint

This branch implements the soil-5 section of [the soil-layer plan](soil-layer.md#ship-use-specific-suitability-screening-soil-5). That section remains the release contract. This checkpoint is not a claim that every release gate has passed.

## Implemented behavior

- `Store` records each successful county/source fetch as an immutable polygon set with UUID references, geometry, map-unit keys, spatial versions, and available survey dates. `StoreWithSet` returns the committed set ID for required screening. Screening rejects a changed set head before publication. Historical polygon rows and legacy joins remain intact. Duplicate source IDs fail both fetch validation and persistence validation.
- Required USDA requests use distinct keys in batches of 50 with a one-request-per-second limiter and caller cancellation. Optional names alone retain the five-second timeout. All three required rule identities and Dominant Condition aggregation parameters are validated. Omitted rows fail the generation. Explicit null ratings remain unavailable; the original `Not rated` phrase remains distinct.
- USDA catalog revisions and raw save timestamps are retained. Calendar dates discard the source's timezone-free clock time. Missing revisions stay unknown. Component identities, percentages, ratings, original reasons and severities remain separate from located parcel acreage.
- `screen` persists fresh intersections and assessments for every stored county/source parcel, including improved parcels, before switching the interpretation/assessment head in the same transaction. No legacy `soil_polygon_parcels` area enters the assessment.
- `CurrentAssessment` returns typed per-use areas, shares, source evidence, reasons, contributing polygon UUIDs, mapped evidence warnings, next steps, and freshness. Same-key coverage is unioned. Cross-key overlap is ambiguous regardless of rating agreement. Edge-only contact contributes zero area. Missing/zero-area geometry is unavailable.
- Areas use EPSG:2264 US survey feet divided by 43,560. Rated, unrated, uncovered, and ambiguous partitions must reconcile within the greater of `1e-7` acre and `1e-8` times parcel acreage. No positive-area sliver is discarded to meet that tolerance. Map-unit mapped areas include ambiguity and must not be summed as exclusive acreage. Component reason areas are never summed.
- Assessment identities and interpretation identities remain stable across refreshes. Each immutable run retains its parcel geometry fingerprint, geometry-set fingerprint/UUID, interpretation-run UUID, method, and calculation time. Reads mark evidence stale after parcel geometry changes, soil-set content changes, refresh failure, method changes, or expiration.
- The executable uses the existing jobs runner for separate source and derived-screening outcomes. No scheduler was added. The existing ten-minute overall deadline remains. Each explicit executable run refreshes evidence; `SOIL_SCREENING_MAX_AGE` configures maximum published age and defaults to 720 hours, including unknown source/rule revisions.
